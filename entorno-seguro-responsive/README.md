# Entorno Seguro - Aventura Educativa

Proyecto web interactivo para un taller de 60 minutos dirigido a primaria.

## Estructura
- `index.html` — estructura y contenido HTML.
- `css/styles.css` — estilos originales + ajustes responsive.
- `js/script.js` — navegación, tarjetas, cuestionario, cronómetro, iconos y diploma.
- `README.md` — documentación básica.

## Uso
1. Abre la carpeta en Visual Studio Code.
2. Abre `index.html` con Live Server, o abre el archivo directamente en un navegador.
3. Se requiere conexión a Internet para cargar Google Fonts, Tailwind CDN y canvas-confetti CDN.

## Responsive
Se agregaron reglas para:
- teléfonos pequeños (hasta 420px),
- celulares/tablets (hasta 767px),
- tablets (768–1024px),
- botones y tarjetas adaptables,
- diploma adaptable e impresión.

El contenido, textos, preguntas y lógica original se mantienen.
